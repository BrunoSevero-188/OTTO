# OTTO

Assistente pessoal em arquivo único. Interface, estilos e JavaScript estão embutidos no arquivo otto.html.

## Como usar

1. Crie uma chave em https://console.anthropic.com/.
2. Abra otto.html no Chrome.
3. Cole e salve a chave da API.
4. Clique em ATIVAR SISTEMA e permita o microfone.
5. Diga “Olá OTTO” e, depois da resposta, fale seu comando. Também é possível digitar no campo.

As notas do Second Brain e a chave da API ficam no armazenamento local do navegador. Voz e reconhecimento dependem do suporte à Web Speech API. A chamada à Anthropic é feita diretamente pelo navegador.
